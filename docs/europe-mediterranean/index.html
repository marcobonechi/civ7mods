Europe, Mediterranean, North Africa

A map mod for Sid Meier's Civilization VII: Europe, the Mediterranean basin and Africa above the Equator on a hand-drawn hex map, with historical start locations for the civilizations of the region.

Get it on GitHub All mods by genginsbon Install Screenshots

What it is

The mod adds map types that reproduce the real geography from the Urals to Iceland and from the Gulf of Guinea to the Persian Gulf. Coastlines, seas, straits, lakes, mountain ranges, biomes, rivers and volcanoes are drawn as longitude and latitude data and projected onto the hex grid when a game starts, so the same geography works at every supported grid size. The Arctic and the Sahara are compressed vertically to give Europe and the Mediterranean the room they deserve, and the Sahel, Ethiopia and Arabia are still there for Aksum, Songhai and the Middle East.

Europe, Mediterranean, North Africa

Urals to Iceland, Morocco to the Sinai. Works with the standard map sizes (Tiny to Huge).

Europe & Mediterranean (Distant Lands)

Reaches south to the Sahel, Ethiopia and Arabia. More hexes per country (Italy and Sicily fit several cities), a harsher Russia, historical starts for Aksum and Songhai. Africa counts as Distant Lands across the Mediterranean, so the Exploration Age treasure fleets and legacy paths work.

Three sizes: 112x98, 128x112 and 144x126.

Europe & Mediterranean (One Landmass)

The same geography with no Distant Lands: Africa and Eurasia share one landmass, so every civilization can be reached overland from turn one. The distant-lands legacy paths cannot be completed on this version.

Historical start locations

Civilizations from the region begin where they did in history. Everyone else is placed on a curated site (Kyiv, Uppsala, Fez, Krakow, Trondheim, Copenhagen, Marrakesh, Budapest, Dublin, Lisbon, Seville, Damascus, Belgrade, Tbilisi and more), as far from the other players as possible.

Install

  1. Get the files: git clone https://github.com/marcobonechi/civ7mods.git, or use Code → Download ZIP on GitHub and unpack it.
  2. Copy the EuropeMediterranean folder into the game's Mods folder: 
    Windows:  %LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods
macOS:    ~/Library/Application Support/Civilization VII/Mods
  3. Restart the game. It reads mods only at startup and enables new ones automatically.
  4. In game setup choose one of the map types listed above. The large maps bring their own three sizes; the standard map uses the game's usual sizes.

The repository also holds the Byzantium, Etruscans and Tuscany civilizations, a browser-based geography editor with live preview, and the scripts that rebuild the previews and these screenshots.
