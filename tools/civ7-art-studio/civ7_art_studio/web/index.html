Improvements

Copy attachments from an existing improvement. You can name the asset whatever you like, as long as its unique, i would recommend a modder prefix. Important to note that some improvements have a requirement of adjacent hexes. Like for example, the Shore Battery improvement needs an adjacent MARINE_BIOME to face, otherwise it wont show. In future, will support that sort of thing too, and custom rotation.

Audio

Wwise 2022.1 converted .wem files only. This software is free at https://www.audiokinetic.com/en/download.

Converting in Wwise 2022.1
Import as Sound SFX in Actor-Mixer Hierarchy.· conversion Vorbis, quality 8, mono · uncheck Stream · right-click → Convert · take the file from <Project>/.cache/Windows/SFX/. Will have a more detailed guide in future.
The donor supplies bus routing. Pick 2D / UI for voice lines and interface sounds; 3D / world positions the sound in the world, which is right for ambience and wrong for a line played from a menu.

Keep blank to copy the donor unit. Not currently supporting customisation for movement, formation, embark and heal references.

3D assets

Imported from glTF. Z is up and a world unit is about a tenth of a metre, so a person is roughly 18 units tall.

Exporting from Blender
Format glTF Binary (.glb) · +Y Up on · compression off.Normals and UVs on. Skinned meshes import their geometry, but bone weights are not written yet.
Blender Metres to game Units. 10 metres makes a human 1.8m model 18 units. makes a 1.8 m model about 18 units. Currently dropping the model so its lowest point rests on the ground. This may be an option in future for building foundations handling rough terrain/elevation.

Materials

A material is a combination of several texture maps. This includes a BaseColor, Tint (for leader colour), Normal map for 3d like effect, RoughMetal and Ambient Occlusion.

Materials can only use textures declared here, even if they exist in base game.
